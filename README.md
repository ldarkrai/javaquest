# ☕ JavaQuest – Aprende Java Jugando

**JavaQuest** es una plataforma web educativa, interactiva y gamificada diseñada para enseñar los fundamentos de la programación en Java desde cero. Los estudiantes pueden avanzar por distintos "mundos", superar retos de código y competir por el primer lugar en el ranking.

![JavaQuest Preview](https://cdn.imgchest.com/files/f6b27dfcdd01.png)
> *Imagen de previsualización.*

---

## ✨ Características Principales

* **Gamificación Integrada:** Sistema de puntos, temporizador, vidas (❤️) y recompensas visuales (confeti) al completar retos.
* **Múltiples Tipos de Retos:**
  * Opción Múltiple.
  * Verdadero o Falso.
  * Emparejamiento de Conceptos (Match).
  * Completar el Código (Fill in the blank).
  * Clasificación (Drag & Drop).
* **Ruta de Aprendizaje Estructurada:** 8 mundos progresivos que abarcan desde "¿Qué es programar?" hasta "Arrays" y "Retos Finales".
* **Panel de Administración:** Un dashboard protegido para ver estadísticas generales, gestionar usuarios y resetear puntajes.
* **Persistencia de Datos:** El progreso, puntaje y ranking se guardan localmente en el navegador (`localStorage`), permitiendo retomar el aprendizaje sin necesidad de base de datos.
* **Personalización y Accesibilidad:**
  * Modo Claro y Modo Oscuro (Glassmorphism UI).
  * Efectos de sonido integrados (Web Audio API) con opción para silenciar.
  * Diseño 100% responsivo para móviles y escritorio.

---

## 🛠️ Tecnologías Usadas

Este proyecto está construido enteramente con tecnologías web estándar. No requiere instalación de dependencias, frameworks ni configuraciones de servidor complejas.

* **HTML5:** Estructura semántica.
* **CSS3:** Variables nativas, animaciones `@keyframes`, Flexbox, Grid y efectos Glassmorphism.
* **JavaScript (Vanilla):** Lógica del juego, manejo del DOM, Web Audio API y uso de `localStorage`.

## 🚀 Instalación y Uso

Dado que el proyecto no usa un backend, probarlo localmente es sumamente rápido:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/ldarkrai/javaquest.git

```

2. Entra a la carpeta del proyecto:
```bash
cd javaquest

```


3. Abre el archivo `index.html` directamente en tu navegador web moderno favorito (Chrome, Firefox, Edge, etc.).
4. ¡Ingresa un nombre de usuario y comienza a aprender!

---

## ⚙️ Acceso de Administrador

El proyecto incluye un panel de administración para gestionar los perfiles locales y ver estadísticas generales.

* **Acceso:** Haz clic en el ícono del engranaje (⚙️) en la barra de navegación superior.
